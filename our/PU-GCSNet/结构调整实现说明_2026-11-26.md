# PU-GCSNet 结构调整实现与运行说明

日期：2026-11-26。依据用户提供的《PU-GCSNet 下一版结构调整详细方案》实现。

本文记录代码行为。新结构尚未完成服务器正式训练，不能据此声称 CD、HD 或 P2F 提升。

## 1. 实现内容

- `network/PUCRN.py`：SubNetwork 可返回与坐标对齐的特征、parent_idx/child_idx；CRNet 负责跨阶段传递。关闭新模块时保留 E0/E6 原权重键和原坐标路径。
- `network/geometry_feature_bridge.py`：沿用16-NN、FP32、stopgrad PCA，尺度为原 E6 邻域距离 RMS；使用无量纲二次曲面岭回归拟合、归一化特征值、拟合残差、邻距离散程度、特征值间隙等13维描述，桥接 Stage1 特征。
- `network/learnable_surface_generator.py`：保留 E6 原预测中心、法向、二次曲面参数与确定性两子点；增加有界切向偏移、可选小法向偏移、可选可靠度门控；为使用细化跳连的配置编码128维子点特征 F2。
- `network/cross_stage_refiner.py`：融合原 Stage3 特征、F2、可选父点特征及几何描述；保留原回归器及其限幅，再添加有界切向／法向修正。可选局部 kNN MLP/max 聚合。
- `network/variants.py`：集中保存配置预设；`compare/run_retraining.py` 支持这些配置及 JSON 开关覆盖。
- `compare/stage_diagnostics.py`：读取正式 raw `best.pth` 和其配置，在独立整物体验证集诊断 P1/P2/P3、FPS 前后误差、双向覆盖、P2F/P99、位移分解与局部拟合质量；不生成图片。

特征桥不是只做旁路记录：其修正量实际加到 Stage2 原特征上，并进入原曲面参数头；启用跨阶段细化时，父点特征与 F2 继续参与 Stage3。因此 M0 也有真实的坐标影响路径。

几何描述使用拟合系数的轴符号不变量；原始6维拟合系数另存于 aux。生成坐标仍使用原 E6 的局部基和可学习二次曲面，保留近重根情况下的坐标轴歧义，不承诺整个网络旋转等变。

新残差投影末层零初始化，几何桥残差系数为0.1；默认关闭几何置信度衰减和额外法向生成，使初始坐标复现 E6。零初始化会让部分新分支内部层在首步梯度为0，输出投影更新后梯度开放。

## 2. 配置预设

| 配置 | Stage1几何桥 | 学习切向生成 | F2跳连 | 父点特征/几何跳连 | 切/法向细化头 |
|---|---|---|---|---|---|
| E6 | 关 | 关 | 关 | 关 | 关 |
| M0 | 开 | 关 | 关 | 关 | 关 |
| V1a | 关 | 开 | 关 | 关 | 关 |
| V1 | 开 | 开 | 关 | 关 | 关 |
| V2a | 关 | 关 | 开 | 关 | 关 |
| V2 | 关 | 关 | 开 | 开 | 开 |
| V3 | 开 | 开 | 开 | 开 | 开 |
| Tail-only | 关 | 关 | 关 | 关 | 关 |

Tail-only 保留 E6 原损失，单独移除旧局部位移限幅。其余预设保留限幅。V3 是组合候选，已有代码不等于已有实验收益。

默认新增幅度均以父点原 E6 RMS 尺度为单位：生成切向0.25、可选生成法向0.1、细化切向每轴0.1、细化法向0.05。细化几何残差加在限幅后的基础位移上，因此最终总位移不再被宣称严格限制在0.5倍尺度内；基础位移和附加位移分别记录。

所有结构组保持原 E6 损失：三级 CD + 0.1×P2切平面监督 + 10轮warmup×(0.05×双向尾部 + 0.05×对应误差增长)。P1训练GT为FPS的512点，P2/P3为1024点。

## 3. 先执行独立验证诊断

以下为服务器 Linux 命令，在 `/home/zk/Gaussian`、`scdata-v3` 环境运行。数据和已有权重目录沿用当前正式归档。命令仅作为后续运行入口，本次没有连接服务器执行。

```bash
conda activate scdata-v3
cd /home/zk/Gaussian

CUDA_VISIBLE_DEVICES=0 PYTHONPATH=compare/.pugaussian-runtime/python python -u compare/stage_diagnostics.py \
  --model-dir compare/retrain-runs/train-seed42-20261123-161953-503869/pu1k/E6 \
  --prepared-root data/repro_20261123_seed42 \
  --dataset pu1k \
  --output compare/retrain-runs/e6-validation-stages-pu1k-20261126

CUDA_VISIBLE_DEVICES=0 PYTHONPATH=compare/.pugaussian-runtime/python python -u compare/stage_diagnostics.py \
  --model-dir compare/retrain-runs/train-seed42-20261123-161953-503869/pugan/E6 \
  --prepared-root data/repro_20261123_seed42 \
  --dataset pugan \
  --output compare/retrain-runs/e6-validation-stages-pugan-20261126
```

输出目录必须尚不存在。`--limit 1` 可先做单物体健康检查，报告会标记 subset；完整诊断去掉此参数。`--save-points` 才会额外保存 XYZ。

输出 `per_shape.csv`、`summary.csv`、`movement.csv`、`protocol.json`。正式指标独立归一化；`shared_*` 列共享输入中心和半径；P2F使用原坐标。P2/P3最终均8192点，候选点保留对应关系；P1最终4096点，不属于等点数比较。若无网格仍可推断和计算点集指标，P2F列缺失时不得声称已算P2F。

## 4. 首轮训练运行方式

先查看配置，无CUDA/数据开销：

```bash
python compare/run_retraining.py --plan --models V1a V1
```

仍为两个数据集独立训练、seed42、batch16、100轮，每5轮及末轮整物体验证，按验证 CD 选同一个 best；PU1K学习率间隔200000 step，PU-GAN为100000 step。

先在服务器做与当前代码匹配的原生 smoke，再训练 V1a：

```bash
python -u compare/run_retraining.py --smoke --models V1a V1

python -u compare/run_retraining.py \
  --prepared-root data/repro_20261123_seed42 \
  --models V1a
```

检查 V1a 的验证曲线和阶段诊断后，再按需运行 `--models V1`。V2a/V2同样先smoke再正式训练；待两条分支各自验证后再考虑V3。

每次自动创建新的运行目录，终端打印路径。恢复时使用相同模型/数据集/参数加 `--resume-run <原运行目录>`。代码变更会使原 smoke 证书失效；旧训练运行的原始源码指纹保护仍保留。

新结构组训练完成后**默认不运行测试集**，会保存 `test_evaluated=false`。汇总写入 `pu1k_validation_summary.csv` / `pugan_validation_summary.csv`，其中指标为原始值，不乘1000。旧四模型默认行为保持原样。

`config.json` 保存解析后的网络和损失；`manifest.json` 保存源码、数据清单哈希和原生参数。训练JSONL新增几何质量、学习偏移、主要分支梯度范数；`validation.csv` 记录每次验证的整物体推断耗时（CUDA同步计时，排除XYZ读写和指标计算）；`performance.json` 保存参数量、进程CUDA峰值显存和best轮次的验证推断耗时。峰值显存包含训练与验证，不等于纯推断显存。

## 5. 开关消融与最终测试

正式入口支持 `--structure-config 文件.json`，格式为模型名到网络覆盖项的映射，例如：

```json
{
  "V3": {
    "learned_normal": true,
    "geometry_gate": true,
    "use_neighborhood_refine": true
  }
}
```

这只是可选配置格式示例，首轮不建议同时打开三项。所有开关和幅度在 `network/variants.py` 中列出；覆盖值写入每个任务的config，并进入smoke指纹。每组消融使用新的运行目录，原损失保持不变。

结构及权重在验证集上确定后，可对选定的新结构显式运行一次全量测试（下面的运行目录需替换为实际完成的正式运行目录）：

```bash
python -u compare/test_examples.py \
  --training-run compare/retrain-runs/实际正式运行目录 \
  --prepared-root data/repro_20261123_seed42 \
  --models V1a --all-shapes --metrics --no-previews
```

此入口核对训练时的prepared manifest，严格加载该组raw best，保留原patch/FPS及统一评测；新建独立测试输出。它不会修改选模结果，也不会自动改为测试指标最好的epoch。
