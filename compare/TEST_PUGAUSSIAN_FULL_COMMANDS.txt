三、严格的完整性检查

默认输入数据根目录取自正式训练归档：
/home/zk/Gaussian/data/repro_20261123_seed42/

默认参照正式运行：
/home/zk/Gaussian/compare/retrain-runs/train-seed42-20261123-161953-503869/

开始推断前逐项检查：
1. 正式参照运行已完成，且不是smoke。
2. PU1K恰好127个、PU-GAN恰好27个输入。
3. 输入、GT、网格的文件名集合完全对应。
4. 物体集合和每份输入/GT/网格哈希与正式测试protocol.json一致。
5. 每个数据集使用自己的官方预训练权重，记录SHA256。

因此，只有几个样例的目录会被拒绝，不会悄悄得到部分数据的“全量汇总”。
本入口复用正式运行中的PU-Gaussian配置与数据协议，不需要重新训练，也不需要训练H5参与前向推断。

只想先检查文件与计划、不推断、不创建结果目录：

python compare/test_pugaussian_pretrained_full.py --plan

如确需只测一个完整数据集，可显式指定；仍会要求该数据集的全部物体：

python -u compare/test_pugaussian_pretrained_full.py --datasets pu1k
python -u compare/test_pugaussian_pretrained_full.py --datasets pugan

更换数据或权重目录时可使用：
--training-run /完整正式运行目录
--prepared-root /新数据根目录
--pretrained-root /官方权重文件夹

四、输出与指标

每次自动新建目录，例如：

compare/test-runs/test-时间戳-pugaussian-pretrained-full/
  run.json                           # test_scope=full-test-set；全部对象、哈希、权重来源、配置
  files.csv                          # XYZ/PLY相对路径与点数
  README.txt
  jobs/                              # 两个数据集分别保存任务、日志、结果与推断参数
  metrics/
    summary.csv                      # 两行：PU1K的127物体均值、PU-GAN的27物体均值
    per_shape.csv                    # 154行逐物体指标
    protocol.json                    # 计算口径、数量、权重来源与哈希
  pu1k/物体名/
    input_2048.xyz / .ply
    gt_8192.xyz / .ply
    gt_mesh.off
    PU-Gaussian-pretrained.xyz / .ply
  pugan/物体名/                     # 同样结构

自动生成同名.tar.gz压缩包，完成后打印Download archive路径。
默认导出完整XYZ/PLY，但不为154个物体逐一绘制PNG，避免大量无必要的预览渲染。
回传后可从完整结果中选取物体制作对照图，指标仍然来自完整测试集。

指标与之前四网络主表一致：
- CD：预测/GT各自质心和最大半径归一化后，双向最近邻平方距离均值相加。
- HD：同一归一化下，两个方向最大平方距离取max。
- P2F：保存坐标下到GT连续三角网格的无符号欧氏距离均值。
- 同时输出两个方向HD和逐物体P2F_P99。
- 显示值均为原始结果乘1000；summary按物体等权平均。

可以将全量summary.csv与之前pu1k_summary.csv、pugan_summary.csv并排诊断。
但请将这一行明确标记为“官方预训练权重”，与当前独立划分下从头重训的PU-Gaussian区分。
官方权重的原始最佳轮次未知，记录为null，不沿用本项目重训的105轮。
这是同一适配推断路径的官方权重对照，不宣称已完成未经适配的官方工具链复现。
